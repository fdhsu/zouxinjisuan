## 简介
一个基于uniapp开发的强大且实用的工具类APP，房贷计算器、文字转换等常用的工具。


## 修改项目Id
 manifest.json文件"appid" : "__UNI__657F005", 调试或者打包请改成自己的项目id
 [dcloud开发者中心-应用管理](https://dev.dcloud.net.cn/pages/common/login?uniIdRedirectUrl=%252Fpages%252Fapp%252Flist)
 
## 安卓调试
1.HBuilderX打开项目
2.手机打开开发者模式，usb连接到电脑上
3.点击HBuilderX菜单上的【运行】-【运行到手机或者模拟器】-【运行到Android app基座】
4.出现设备弹框，点击【运行】或者【重新运行】按钮
5.手机上会HBuilderX，正常会展示app画面
