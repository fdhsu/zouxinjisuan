# 小北工具箱 开源APP

### 简介

一个基于uniapp开发的强大且实用的工具类APP，提供了包括图片处理、测算，信息查询和娱乐等常用的工具。如：文本加密解密、二维码生成与识别、九宫格切图、图片拼接、国旗头像、房贷和BMI计算器等，如同瑞士军刀一样方便好用~
